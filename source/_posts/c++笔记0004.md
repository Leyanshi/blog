### Review: While Cycle
#### Conception
While 循环：
```cpp
while (condition) {
	// if condition then
	cout << "114514";
}
```
`break` 用于跳出**最内层**循环。

```cpp
do {
	// 做一次后判断
} while (condition);
```

### Review: For Cycle
#### Conception
累加 `for`:
```cpp
for (int i = 0; i < length; i++) {
	//do sth
}
```

> 栈变量=局部变量，后进先出

![](https://photos.leyanshi.me/cpp-jb-variable.png)

`continue` 是结束**本次**循环，`break` 是结束所有循环。

### Review: Char Array (String)
Char array的末尾项是0，这是为了查大小；改char array的时候末尾要加`0`或`'\0'`

##### Reverse String
```cpp
#include <iostream>
using namespace std;
int main() {
	char s[100]; cin >> s;
	for (int i = strlen(s); i>=0; i--) {
	cout << s[i];
	}
	return 0;
}
```
